# Hornet Remote Suite

Hornet Remote Suite 二进制安装包发布仓库。项目源码保留在私有仓库，本仓库只包含下载说明、版本说明与校验文件。

当前最新版本为 **[0.0.11](https://github.com/codehubcloud/hornet-remote-suite-release/releases/tag/v0.0.11)**。新增 SSH 断线提示与手动重连，补充 Xshell 风格标签菜单、标签组、独立会话/SSH 渠道复制、批量关闭、锁定防误关及颜色/显示选项。新建或编辑连接时可保存用户名和密码，密码由系统加密并与目标身份绑定，不进入配置导出；重启后可自动认证，首次主机指纹核验保留。覆盖安装保留连接、分组和配置。

SSH 静默网络丢包通常约 45–60 秒后显示“已断开”，保留历史输出并停止输入，可手动重连，不自动重发命令。“将标签移动到窗口”尚未实现，保留灰色；标签锁定是关闭保护，不是密码锁屏。

继续包含 0.0.10 的图标改进：放大任务栏图标的可见主体，修正透明留白导致图标显得偏小的问题：32×32 图标中的清晰主体由 22×24 增至 28×30，保留透明背景、原比例和配色。同步更新各平台程序与安装包图标，覆盖安装保留连接和配置。

继续包含 0.0.9 的改进：新增 Ctrl＋滚轮终端字号缩放：向上放大、向下缩小，每格 1 像素，范围 8–32；仅调整鼠标所在终端，分屏独立，自动同步远端行列数。普通滚轮仍用于滚动，菜单、文件栏和整个界面大小保持不变。覆盖安装保留连接与配置。

继续包含 0.0.8 的改进：终端分屏同时排列标签和内容，每个标签直接位于对应窗格顶部，去掉下方重复标题。继续支持标签右键分割、重命名、合并与关闭，保持现有终端输出和 SSH 连接；文件目录跟随活动终端。修复终端正常退出后残留的输入错误，覆盖安装保留连接与配置。

继续包含 0.0.7 的透明 Logo 和合并式标题菜单栏，保留系统原生窗口按钮、拖动、主题配色和工具栏折叠。

继续包含后台无响应时的退出保障：关闭提示不再等待后台查询，取消后继续运行；确认退出后清理最多等待 5 秒，避免后台或界面卡住时迟迟无法退出。

包含 0.0.4 的后台存活检测、SFTP 错误处理和大文件完整 SHA-256 校验优化：服务器支持时在远端计算摘要，上传后无需回下载整个文件；不支持时自动回退流式校验。继续包含终端复制/粘贴、右键菜单及历史数据库启动兼容性修复；覆盖安装即可，原有连接与配置保留，不需要删除数据库。

从 [Releases](https://github.com/codehubcloud/hornet-remote-suite-release/releases) 下载，首个版本为 **0.0.1**。

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Windows | x64 | EXE 安装程序 |
| macOS | Intel x64 / Apple Silicon ARM64 | DMG |
| Linux | x64 / ARM64 | AppImage、DEB |

请按系统和架构选择安装包，并用每个版本附带的 `SHA256SUMS` 核对 SHA-256。

Windows：`Get-FileHash <安装包路径> -Algorithm SHA256`。

macOS：`shasum -a 256 <安装包路径>`；Linux：`sha256sum <安装包路径>`。

AppImage 下载后需要赋予执行权限：`chmod +x <安装包路径>`。DEB 适用于 Debian/Ubuntu 系统。

SSH/SFTP、FTP/FTPS、Telnet、会话管理、多语言和主题为通用能力。当前原生 RDP、VcXsrv 管理、本地 PowerShell/CMD、串口及系统打印提交使用 Windows 专用适配器。VcXsrv 不随安装包分发，需自行安装。

当前发行版未配置商业代码签名或 Apple 公证。

公开提供安装包不代表项目源码开源，也不授予开源许可；第三方组件按随附许可分发。问题反馈请使用本仓库的 Issues。
